# 纸见 v1.0.5

一个单点修复版本：**上滑收起悬浮页签栏在笔记页与标签页失效**，以及回归时**底栏被摊成满屏宽**的放大。

## 为什么会这样

两件事其实是同一个入口的两种档位。`HdsTabsController` 的显隐只有两个枚举：

| 档位 | 收起 | 展开 |
| --- | --- | --- |
| `SCROLL_ANIMATION` | 收起标题栏**与**页签栏 | 把胶囊摊成满屏宽、图标放大到 1.67 倍再收拢 |
| `CLICK_ANIMATION` | **只收起标题栏**，页签栏留在原地 | 原位做一次缩放淡入 |

v1.0.4 为了绕开「摊成满屏宽」，把两个方向都换成了 `CLICK_ANIMATION`。放大确实没有了，
代价是收起也不再生效——笔记页和标签页上滑之后顶栏走了、底栏还在，读起来就是「收起坏了」。
这两档没有对称解，任何一边选错都会在另一边露出来。

标签页还有第二个原因，是它自己的：「到底」守卫原本整段跳过。列表到底之后继续同向划动，
容器会先给出越过边界的位移、松手再弹回来，而那一截回弹在 `yOffset` 上就是「位置在减小」。
为了不让同一次上滑收起、弹回又叫回来，v1.0.4 在到底期间整套判定都不做。可内容刚过一屏的
页面（标签药丸多到十来行正好这样）第一帧位移就直接落在底部，于是连正方向一起被吞掉，
收起永远不触发。

## 改法

方向决定档位，不再是同一个枚举走两遍：

- **收起** `applyHideAnimation(SCROLL_ANIMATION)` —— 这是唯一会真的把页签栏收走的档。
- **展开** `applyShowAnimation(CLICK_ANIMATION)` —— 原位缩放淡入，不铺满整行。

`setChromeHidden()` 里因此是一个明确的 if/else，不是重复代码：两档的取舍写在同一处，
下一个要动它的人能直接看到为什么不能统一。

到底守卫收窄成只压回弹的那一半（`isAtEnd() && delta < 0`），正方向照常累计；
离开底部之后仍然重新种基准，回弹的余量不会被当成一次猛推。

## 验证

三个页签逐一「上滑 → 收起态抓图 → 下滑 → 回归态抓图」。收起态下的截图里底部条带
完全空白，页签栏真的走了；回归后胶囊回到原位、宽度与常态一致（不铺满整行）——
半分辨率连拍抓到的过渡帧里，胶囊只做原位缩放淡入，没有出现 900 px → 1320 px 那一档。
笔记页用 14 条笔记撑开、标签页用 60+ 标签撑开——内容不足一屏时容器不产生滚动，
`onDidScroll` 不触发，那个页签本来就没有「收起」可言。

判据与两档的取舍一并写进 `AGENTS.md` §「滚动时顶栏与页签栏一起让位」。
