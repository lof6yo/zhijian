# 纸见 v1.0.2

一个「交互打磨」版本。v1.0.1 之后又收了几处细节，本条改动是切页签时的筛选带。

## 切页签时筛选带不再瞬移

设置页没有筛选条 / 排序条，所以从笔记页、标签页切过去时，控件、页面留白和标题栏
底边原来会在同一帧里一起跳掉 50 vp——看起来像被抠走一块。

现在由三个状态驱动：

| 状态 | 作用 | 能否插值 |
|---|---|---|
| `bandFading` | 带内两条胶囊的 `opacity` | 是（纯属性动画） |
| `bandInset` | 页面顶部留白里属于带子的那段，`0…50` | 是（`animateTo`） |
| `bandShown` | `bottomBuilder` 挂不挂 | **否**（HDS 构建参数） |

关键是最后一行：`bottomBuilder.height` 是交给 HDS 的构建参数，不是节点属性，
`animateTo` 对它无效，所以它只取两档，且只在带子不可见时翻转。真正会动的是
`bandInset`——`titleBandHeight()` 读它，于是笔记网格、标签列表、设置页三者一起
平移，不可能有一处先到。

两个方向的段数因此不同，因为坑不一样：

- **收起**：控件淡出 → 留白与结构一起收。
- **展开**：留白撑开 → 挂结构 → 控件淡入。

结构**摘掉**不影响 padding 的插值（摘完 padding 还在动），结构**插入**会让
`animateTo` 把 padding 重算成终值、插值被跳过——实测展开方向 `外观` 一帧从
419 px 跳到 313 px 再跳回 435 px。所以展开时必须先让留白走完再挂结构。

实测（深色，卡片顶边 px）：收起 369 → 417 → 441 → 453 → 459，
展开 309 → 341 → 419 → 449 → 459，两个方向都连续无跳变。

带子还带了自己的页签 `bandTab`：否则那 140 ms 的淡出里，笔记页的筛选条会先换成
标签页的「全部 / 在用」「名称 / 数量」再消失。

三个入口都走同一条路径：页签栏（`switchTab`）、标签下钻（`filterByTag`）、以及
删掉最后一个标签（`refreshList`，那一刻标签页的带子要收起来，而它不是一次切页签）。
