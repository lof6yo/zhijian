# 纸见 v1.0.0

本地优先的 HarmonyOS NEXT 笔记应用：Markdown 是唯一真源，渲染、编辑、搜索、同步全部原生实现。

## 本次发布

### AI 洞见：左重划自动打标签

笔记卡片向左重划到底，AI 会读这篇笔记并打上 2–4 个标签。

- **合并，不覆盖。** AI 给的是建议，已有的标签一个都不会掉；落盘前还会再读一次当前值，请求在飞的十几秒里你手动加的标签同样不会被盖掉。
- **复用，不造近义词。** 提示词里带上库里全部标签要求「意思相同就复用」，解析后再做一次代码层的归一比对（大小写 / 空白）——提示词管不住模型的手，代码能。
- **新建标签不需要额外步骤。** 标签写进 frontmatter 就出现在标签页。
- **手势必须有进度。** 松手后卡片立刻回弹，界面上没有任何东西还停着表示「在做」，所以加了一条浮在页签栏上方的进度胶囊（不拦手势）。

### 新应用图标

图标换成了设计稿 `design/my-icon.png`：白色几何图形 + 3×3 蓝色马赛克底。

`scripts/gen-icon.ps1` 不画任何线条，只把这张母版拆成 HarmonyOS 分层图标要求的两层。拆法是**反解 alpha**而不是按亮度切：

```
src = a × 255 + (1 − a) × bg    →    a = (src − bg) / (255 − bg)
```

能这么解，是因为 `bg` 是确定已知的——母版是 3×3 纯色马赛克，每像素属于哪一格可以算出来。脚本末尾有端到端断言：把拆出来的两层合成回去必须还原母版，当前 **max 通道误差 1、mean 0、超 12 的样本 0 / 350892**。

背景层保留了马赛克花纹。「背景层建议使用纯色」是设计建议不是校验项，但图形底下那块补成了底色——留白会在两层缩放不一致时露出一道白边。

### 阅读与编辑

- **没有阅读 / 编辑开关。** 打开就是渲染态，点正文就地进入编辑；`+` 新建的笔记直接开始写。
- **两种编辑体验**（设置 › 编辑体验）：分块（默认，源文在上、渲染在下）与简单（整篇一个输入框，沿用阅读态排版）。
- 正文与代码块可长按选中、弹出系统复制 / 全选菜单。
- 撤销 / 重做记的是整篇正文快照，AI 结果替换正文后同样可撤销。

### Markdown 引擎

自研、原生渲染：标题、列表、任务、引用、表格、代码高亮、行内公式（`MathLite` 转 Unicode）全部走 ArkUI；只有块级 `$$…$$` 交给 ArkWeb 里的离线 KaTeX。

### WebDAV 同步

三路合并 + 基线，而不是靠时间戳猜：

- 同步身份是 frontmatter 里的 `id`，不是文件名。
- 删除双向传播——本地进回收站（30 天），远端进 `zhijian/.trash`。
- 一次同步只写「确认到达服务器」的基线行；写未确认的行会让下次同步拿旧远端盖掉新本地。
- 一个 id 只允许一个远端路径；改名留下的旧文件会被清理。
- 密码存在 Asset Store Kit，不进 preferences，输入框永不回填。

### 安装

附件是 **release 构建的未签名 HAP**（1.18 MB）。装到自己的设备上需要先用自己的证书签名：

```powershell
# 用 DevEco CLI 生成签名配置，再装
devecocli auth login --no-prompt
devecocli signature generate --product default
hdc install -r zhijian-1.0.0-release-unsigned.hap
```

开发机上的本地调试签名（`scripts\run.ps1`）只对模拟器有效，不随包提供。

## 已知边界

- AI 与 WebDAV 都需要自己填端点 / 服务器；应用本身不内置任何服务。
- 自动同步只在前台做，后台不发请求。
- 图表（Mermaid / ECharts）已从包内移除——过去 6.5 MB 引擎从未被任何 UI 路径触达。
