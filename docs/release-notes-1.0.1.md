# 纸见 v1.0.1

一个「交互打磨」版本：没有新功能，改的全是手指碰到的那几处。

## 本次发布

### 筛选条 / 排序条搬进标题栏

它们原来画在页面内容区，只能用一个不可见的 `Toggle` 当载体去模拟沉浸光感——因为
`systemMaterial` 的作用域是标题栏、底部页签栏和少数几个控件，「在其他区域中设置
沉浸光感效果不生效」。搬进 `titleBar.content.bottomBuilder` 之后，胶囊自己就在
作用域里，拿到的是真的材质。

- 载体在本页不再需要（卡片与标签药丸仍需它，未动）。
- 代价是标题栏多了一条 50 vp 的带，页面顶部留白由 `titleBandHeight()` 统一算。
- 副作用是好的：它们跟着标题栏一起显隐，不必再手工算胶囊该收多少。

### 筛选项与排序项：选中态会滑过去

切换时原来没有任何位移——每个 chip 各画一块圆角底色，两处交叉淡入，读起来像
「闪了一下」。现在是一块 28 vp 的指示器在三格之间平移（260 ms `FastOutSlowIn`），
chip 自身永远透明。

- 排序方向改成一颗常驻的 `↓` 旋转 180°，未选中时 `opacity 0`。换字形会改字宽，
  箭头一出现标签就被推开一格。
- 去掉了 `fontWeight` 跳变：离散属性没有中间帧，会在滑动途中插一次硬跳。
- 格宽由 `chipSlotWidth()` 从实际显示宽度反查，平板与手机同一套。

### 卡片左右滑动：越界那段改成淡出，不是切断

卡片宽度就是单元格宽度，一滑动必然越过它，而 `FlowItem` 会裁在格边——删掉
`.clip(true)` 也没有任何变化，切口是既成事实。裁下去是一条竖直直线，卡片平时那
一侧却是圆角，「被切得很突然」；这条线落在哪还取决于那一侧有没有邻居，最外侧的
列旁边只有页面留白，同一行两侧必然不同。

现在 `EdgeFade()` 在格边最后 44 vp 内做**空间渐隐**（`linearGradient` +
`blendMode(DST_IN, OFFSCREEN)`）：让切口线上没有像素可被切。实测格边色差从 24 个
色阶降到 1（浅色）与 0（深色）。

四档语义、判定线、卡片圆角都没变。

### 顶栏收起后，网格上边界也淡出

顶栏一走，网格视口的上沿就落在状态栏下 8 vp 处，滚到那里的卡片被裁成一条直线，
一排卡片的高光边缘齐刷刷断在同一个 y 上——比「顶栏不在了」这件事本身还显眼。

用的是平台能力 `.fadingEdge()`，按 alpha 把内容渐隐到真实背景，深浅主题与强调色都
不用各写一份，与卡片横滑的 `EdgeFade()` 是同一套语言。渐隐长度 40 vp。

## 安装

附件是 **release 构建的未签名 HAP**。装到自己的设备上需要先用自己的证书签名：

```powershell
devecocli auth login --no-prompt
devecocli signature generate --product default
hdc install -r zhijian-1.0.1-release-unsigned.hap
```

开发机上的本地调试签名（`scripts\run.ps1`）只对模拟器有效，不随包提供。

## 已知边界

- AI 与 WebDAV 都需要自己填端点 / 服务器；应用本身不内置任何服务。
- 自动同步只在前台做，后台不发请求。
- 图表（Mermaid / ECharts）不在包内——过去 6.5 MB 引擎从未被任何 UI 路径触达。
